# Fetify

Landing page de Fetify — mise en relation avec des prestataires pour les événements de vie (mariage, baptême, anniversaire, soirée entre proches).

## Contenu

- `index.html` — page unique (auto-portante) : présentation, annuaire des premiers prestataires, formulaires d'inscription (client et prestataire).

## Développement

Le fichier `index.html` ne dépend d'aucun outil de build : ouvrez-le directement dans un navigateur pour le prévisualiser.
